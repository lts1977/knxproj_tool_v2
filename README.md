一、本软件做什么

把 ETS 工程 .knxproj 解析为网关可直接部署的 eibDatabase.db,
并直连正爵/KTS 网关在线运维:登录会话、自动备份、一键部署、盈趣(Intre)
融合写参。产出模型由 V1(v1.6.0)实机验证,不重写、只升级。

二、五个页签工作流

| 页签 | 作用 | 你在这里做什么 |
| 工程导入 | 打开 .knxproj → 解析 | 选工程文件、查看解析摘要与房间分布、生成 .db |
| 对象编辑/校验 | 表格总览与质量审计 | 筛选/双击编辑对象、型号自检与一键修复、型号分布、导出映射清单 |
| 网关部署 | 在线备份与整库部署 | 连接网关后:手动备份、查看备份历史、恢复、一键部署向导 |
| 盈趣对接 | Intre 融合配置开关 | 勾选启用后才写 Intre. 型号与对接参数;对照表/示例/一键写参 |
| 帮助中心 | 内置文档 | 本手册/融合规则/接口速查/型号表/常见问题/版本记录 |

推荐顺序:顶栏「连接管理」连上网关 → 工程导入 → 对象编辑校验(修复型号) →
生成数据库 → 网关部署(自动备份→一键部署) → 盈趣页确认开关状态。

三、顶栏连接管理

• 网关 IP:输入后回车记忆;下拉里是最近连接历史;点「扫描发现」自动探测
  同网段网关候选。
• 连接:建立 HTTP 连接并登录(默认 admin)。双状态灯:
  - 连接灯:灰=未连接 / 黄=连接中 / 绿=已连接 / 红=连接失败
  - 登录灯:灰=未登录 / 绿=已登录 / 黄=会话已过期
• 登录成功后,行 2 回显设备型号/固件/本机 IP(部分网关型号需在后台页面核对)。
• 空闲自动退出:默认 10 分钟无操作自动退出登录(清会话、灯转灰),
  可设 1~120 分钟或 0=永不。此为软件侧会话管理,网关自身超时独立。

四、常见操作路径

1. 从零转换:工程导入 →「打开 .knxproj」→ 自动解析;摘要卡给出对象/房间/
   未识别地址 →「生成数据库」选保存位置。
2. 质量审计:切到「对象编辑/校验」→ 点「型号自检」→ 红色=非法型号、
   橙色=建议型号 → 点「一键修复非法型号」→ 再自检应全绿。
3. 在线部署:确认已登录 →「网关部署」→ 建议先「手动备份」→ 选生成库 →
   「一键部署」→ 向导自动完成「备份 → 上传清空库(先清除网关原有工程内容)
   → 上传本次库」,全程零残留;完成后必须重启网关新库才加载生效。
4. 盈趣融合交付:确认甲方使用盈趣 APP 时才勾选「启用盈趣」,填盈趣网关 IP
   (端口固定 41709)→「一键写参到网关」→ 重启网关后设备在 APP 上传显示。
   开关对已导入对象同样即时生效,无需重新导入:勾选后点「生成数据库」或
   「一键部署」会自动为可判定对象补 Intre. 型号(灯光按 EIS 判 KL01/02/03、
   窗帘按名称+行程分卷帘 KLA01 / 开合帘 KLA02(含停止/位置加 T)、空调/地暖/新风
   组补 KA01/KF01/KW01);不勾选时绝不写入任何型号。

五、安全与回滚

• 所有写操作(部署/恢复)前强制自动备份到 backups\,
  文件名 eibDatabase_日期_时间_序号.db,序号保证不覆盖。
• 备份历史可一键恢复;恢复同样先备份当前库。
• 基线库 eibDatabase_20260904_baseline.db 是网关出厂配置,恢复时二次确认。
• 危险操作(恢复/部署/重启)都有二次确认弹窗。

六、小提示

• 对象行里的型号一律以 Intre. 前缀填写,编码表在「盈趣对接」页与
  「03_型号编码表」帮助文档中。
• 空调/地暖/新风设备在网关里以「对象组大卡」呈现,子对象型号留空属正常;
  灯光/窗帘/传感器请务必自检通过后再部署。
• 清单与报告导出到 out\ 目录。
